# Potion art

The user's AI potion pictures, cut out of their white background (border flood-fill),
cropped square and saved at 512x512. Uploaded with the Studio MCP `upload_image`.

| File | Used as |
|---|---|
| `potion_<id>.png` (luck, cash, speed, strength, clean) | each potion's `image` in `Config/Potions`: the Potions panel, HUD timer chips, Speed boost chip, Furnace reel, Free Gifts cards |
| `potions_tile.png` | `Potions.TILE_IMAGE`, the Potions HUD tile (cash, luck and speed bottles together) |
